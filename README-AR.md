# Portfolio جاهز للرفع على Netlify

الموقع بنفس الاستايل الحالي، لكن كل البيانات أصبحت قابلة للتعديل من لوحة تحكم Decap CMS على Netlify.

## طريقة الرفع
1. ارفعي الملفات على GitHub repository.
2. افتحي Netlify واختاري Add new site > Import an existing project.
3. اختاري الريبو واضغطي Deploy.
4. بعد النشر، من Netlify فعّلي Identity ثم Git Gateway.
5. افتحي رابط الموقع بهذا الشكل: `/admin` لتعديل البيانات.

## الحاجات القابلة للتعديل
- الاسم والوظيفة والوصف وصورة البروفايل.
- CV file.
- الإيميل والموبايل والعنوان.
- روابط GitHub / LinkedIn / WhatsApp وأي لينك جديد.
- الخبرات والمهارات والتعليم.
- المشاريع وصورها والـ Live Preview والـ Source Code.

## ملاحظة المشاريع
لو عدد المشاريع زاد عن 3، الموقع يعمل Pagination تلقائي بشكل شيك. تقدري تغيري عدد المشاريع في الصفحة من `Projects Settings`.
